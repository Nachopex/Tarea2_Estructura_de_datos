## Sobre el entregable
Este proyecto escrito en C++, permite crear un arbol general a partir de 10.000 archivos XML. Todo esto usando la librería tinyxml2 para extraer los metadatos de los libro

## Sobre la compilación y ejecución
Para probar este proyecto, se debe compilar con 
```
g++ main.cpp tree.cpp tinyxml2.cpp -o tarea2 -std=c++11
```
y para ejecutar `./tarea2`.
